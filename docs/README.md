# Dorsal documentation

Dorsal is an open configurator for the Attack Shark X85 Pro, served at **[dorsal.cotoo.dev](https://dorsal.cotoo.dev)** and shipped as two AppImages.

| Guide | What it covers |
| --- | --- |
| [Architecture](architecture.md) | How the pieces fit: routes, the device layer, the transport, the screen pipeline, the 3D board, languages and the Electron shell |
| [Development](development.md) | Setting up, scripts, environment variables, demo and developer modes, tests and conventions |
| [Deployment](deployment.md) | Publishing the site on `dorsal.cotoo.dev` and distributing the AppImages |
| [Dorsal Screen](dorsal-screen.md) | The mini app that only edits the keyboard's TFT |
| [Troubleshooting](troubleshooting.md) | The keyboard is not found, uploads stall, the 3D is slow, and other known problems |
| [Protocol](protocol.md) | The keyboard's HID protocol, command by command |
| [Roadmap](roadmap.md) | What comes next: music, the background app and profiles |
